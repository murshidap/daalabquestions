1. Start.
2. Read the number of elements `n`. If `n` is less than 1 or greater than 100, display an error and stop.
3. Read `n` elements into array `a`.
4. Call `FindMinMax(a, 0, n - 1)`.
5. In `FindMinMax(a, low, high)`:
   - If `low == high`, return `a[low]` as both the minimum and maximum.
   - If the range contains two elements, compare them once and return the smaller as the minimum and the larger as the maximum.
   - Otherwise, calculate `mid = low + (high - low) / 2`.
   - Recursively find the minimum and maximum in the left half, `low` through `mid`.
   - Recursively find the minimum and maximum in the right half, `mid + 1` through `high`.
   - Return the smaller of the two minima and the larger of the two maxima.
6. Display the returned minimum and maximum.
7. Stop.
