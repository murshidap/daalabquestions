### Algorithm

1. **Start.**

2. Declare two 4×4 matrices `A` and `B`, and a 4×4 result matrix `C`.

3. Read the elements of matrices `A` and `B`.

4. Divide each matrix into four 2×2 submatrices:

   - `A11`, `A12`, `A21`, `A22`
   - `B11`, `B12`, `B21`, `B22`

5. Calculate the seven products using Strassen's formulas:

   - `M1 = (A11 + A22) × (B11 + B22)`
   - `M2 = (A21 + A22) × B11`
   - `M3 = A11 × (B12 − B22)`
   - `M4 = A22 × (B21 − B11)`
   - `M5 = (A11 + A12) × B22`
   - `M6 = (A21 − A11) × (B11 + B12)`
   - `M7 = (A12 − A22) × (B21 + B22)`

   **Note:** Each `M` is a 2×2 matrix. The additions, subtractions, and multiplications are performed on the submatrices.

6. Calculate the four submatrices of the result matrix `C`:

   - `C11 = M1 + M4 − M5 + M7`
   - `C12 = M3 + M5`
   - `C21 = M2 + M4`
   - `C22 = M1 − M2 + M3 + M6`

7. Combine `C11`, `C12`, `C21`, and `C22` to form the 4×4 result matrix `C`.

8. Display the result matrix `C`.

9. **Stop.**
